# Contributing to Lithium

Use a focused branch and open a pull request against the repository's default
branch. Keep unrelated changes in separate pull requests.

A pull request should include:

- a concise description of the change;
- the checks that were run;
- screenshots for visible interface changes;
- affected contracts, deployments, or configuration files; and
- linked issues or discussion context.

Do not commit populated environment files, wallet material, seed phrases, API
credentials, or local deployment state.
