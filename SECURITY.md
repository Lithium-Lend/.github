# Security

## Reporting a vulnerability

Report security vulnerabilities privately through the affected repository's
Security tab by opening a private vulnerability report. Do not publish an
unpatched vulnerability in an issue, discussion, pull request, or social
channel.

Include the affected component or commit, reproduction steps, potential impact,
and a proposed mitigation when available.

Use test accounts and testnet assets. Do not access another user's account,
disrupt service availability, or move funds that you do not own.
